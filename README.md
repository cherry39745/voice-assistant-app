# Voice Assistant Android App

A starter Android app built with Kotlin and Jetpack Compose. It includes:

- microphone-based speech input
- automatic command parsing
- text-to-speech responses
- simple voice assistant behaviors for greetings, time, date, jokes, and fallback replies

## Tech stack

- Kotlin
- Jetpack Compose
- Android SpeechRecognizer
- TextToSpeech
- Material 3

## How to run

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Select an emulator or connected Android device.
4. Press Run.

## Example commands

- "Hello"
- "What time is it?"
- "What is the date?"
- "Tell me a joke"

## Notes

This project is intentionally lightweight and acts as a solid starting point for a more advanced assistant that can connect to real APIs, AI services, or reminder/task features later.
